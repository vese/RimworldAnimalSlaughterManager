# Макеты окна настроек вида (Dialog_KindSlaughterSettings)

ASCII-макеты трёх вкладок с размерами из кода (`Source/AnimalSlaughterManager/Windows/Dialog_KindSlaughterSettings.cs`).
Размеры — в «пикселях» RimWorld (UI units). Ширина окна = 980, высота плавает
(`min(Screen.height*0.85, Screen.height*0.95)`), минимум диктуется вкладкой.

## Шпаргалка по константам

| Константа | Значение | Что |
|---|---|---|
| `InitialSize.x` | 980 | ширина окна |
| `HeaderH` | 34 | шапка (иконка + имя + кнопки) |
| `TabBarH` | 32 | полоса табов |
| `TabGap` | 4 | отступ под табами |
| `TabStripH` | 36 | `TabBarH + TabGap` (резервируемая полоса) |
| `PrefsH` | 128 | 4 строки pref × 30 + gap 8 |
| `CondSectionH` | 60 | строка заголовка (30) + строка кнопок (30) секции условий |
| `DividerGap` | 8 | высота, занимаемая линией-разделителем |
| `SectionNonListH` | 72 | заголовок (30) + help (22) + заголовки колонок (20) секции черт |
| `MinListH` | 150 | минимум списка (Особые правила) |
| `minLH` (tab 0) | 60 | минимум списка условий (Приоритеты) |
| `NonListHeight` tab 0 | 300 | prefs(128)+sep(8)+help(36)+2×60+divider(8) |
| `NonListHeight` tab 1 | 152 | 72 + divider(8) + 72 |
| `NonListHeight` tab 2 | 176 | PrefsH(128) + 8 + 40 |

## Заметки по верстке

- Списки (tab 0, tab 1) **растягиваются** на свободную высоту окна; при сжатии окна ниже минимума включается общий scroll.
- `numLists`: tab 0 = 2 ряда секций, tab 1 = 2 списка → `perList = (inRect.height − NonListHeight) / 2`.
- Окно **не draggable целиком** (`draggable=false`): перетаскивание строки в списке двигало бы окно. Перетаскивается только рамка + шапка/таб-полоса (`LateWindowOnGUI`).
- Табы рисуются на 32px выше базовой точки (`TabDrawer.DrawTabs`) — поэтому `TabStripH` резервируется отдельно.
