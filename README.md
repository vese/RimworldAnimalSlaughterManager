# Animal Slaughter Manager

Мод для **RimWorld 1.6** (`namespace ASM`, на Harmony), расширяющий встроенный авто-забой животных: приоритет по полу×возрасту, списки условий для забоя, цели разведения (защита), принудительный забой, защита конкретных животных, пресеты и менеджер-таблица. Интеграция с Animal Traits System (опционально).

Исходный код: **https://github.com/vese/RimworldAnimalSlaughterManager**

---

## Сборка

Мод — SDK-style `.csproj`, `net472` (RimWorld 1.6 = Unity 2022.3 / Mono). API — через NuGet **`Krafs.Rimworld.Ref` 1.6.*`** (reference-only) и **`Lib.Harmony`** (компилируется в DLL, не требует отдельного мода Harmony).

```bash
dotnet build Source/AnimalSlaughterManager/AnimalSlaughterManager.csproj -c Release     # DLL → Assemblies/
```

Собранная DLL коммитится (в `.gitignore` исключены `bin/`, `obj/`, `*.pdb`, `*.xml`). **Перед коммитом — собрать.**

RimWorld не установлен локально — компиляция против `Krafs.Rimworld.Ref` достаточна. Поведение проверяется в игре.

## Возможности

Расширяет встроенный авто-забой:

- **Приоритет по полу×возраст** — для каждой из 4 групп (взрослые/молодые × самцы/самки) выбор «сначала старших» или «сначала молодых».
- **Списки условий приоритета** (требуется Animal Traits System):
  - Для каждой группы — упорядоченный список условий, определяющий очерёдность забоя (сверху — защищаемые, снизу — забиваемые первыми).
  - Условия: беременность, привязанность, черты (наличие/отсутствие + наследуемость), болезни, тренировка (не обучено / обучено / полностью обучено), положительные/отрицательные черты.
- **Защита (цели разведения)** — оставить N животных с указанной чертой, защищённых от забоя.
- **Принудительный забой** — забивать животных с указанными чертами всегда, независимо от поголовья и других настроек, кроме защищённых чертами и индивидуально.
- **Трёхзначная колонка беременных** — не забивать / отложить до родов (учитываются в пороге, но не занимают место) / забивать как обычно. Яйцекладущие учитываются.
- **Защита конкретных животных** (индивидуально, через гизмо + колонку на вкладке «Питомцы»).
- **Пресеты трёх уровней** — для всех видов / для вида / для списка (с импортом из пресетов верхнего уровня).
- **Таблица-менеджер** в стиле ванильного окна забоя (∞-лимиты, индикаторы настроек у вида).

## Совместимость

- **Animal Traits System** (опционально) — поддержка черт животных. Без ATS мод работает, раздел черт недоступен.
- **Harmony** — встроен в мод (Lib.Harmony компилируется в DLL, отдельный мод Harmony не требуется).
- DLC (Royalty, Ideology, Biotech, Anomaly, Odyssey) — загружается после DLC, но работает и без них.

## Структура

```
About/About.xml               — метаданные мода (описание, зависимости)
Assemblies/*.dll              — скомпилированная DLL (включая Harmony)
Defs/                        — PawnColumnDef (колонка защиты)
Languages/{EN,RU}/Keyed/      — переводы
Textures/UI/Icons/ASM/        — иконки (щит, шестерёнка)
Source/AnimalSlaughterManager/ — исходники (csproj + src/)
AnimalSlaughterManager.sln      — solution для IDE
AGENTS.md                    — справка для агента (архитектура, API, грабли)

```

## Файлы для Steam Workshop

Для публикации мода в Steam Workshop нужны:

1. **About/About.xml** — описание, автор, packageId, совместимые версии. ✓ Готово.
2. **Assemblies/AnimalSlaughterManager.dll** — скомпилированная DLL с Harmony. ✓ Готово (Lib.Harmony компилируется, отдельный мод Harmony не нужен).
3. **About/Preview.png** (опционально) — превью-картинка для списка модов (400×280px). **Нужно создать.**
4. **Скриншоты** — для страницы мастерской. **Нужно сделать в игре и загрузить через Steam.**
5. **Languages/** — переводы (RU/EN). ✓ Готово.
6. **Defs/, Textures/** — контент. ✓ Готово.

### Чего не хватает

- **Preview.png** (400×280px) в `About/` — отображается в списке модов. Можно сгенерировать или сделать скриншот из игры.
- **Скриншоты для мастерской** — загрузить через Steam при публикации (на страницу, не в файлы мода).
- **Проверка совместимости** с другими модами на забой/животных.
- **Тег `modIconPath`** в About.xml (опционально) — путь к иконке мода (128×128px PNG).

Подробная справка по архитектуре, проверенному RimWorld 1.6 API и граблям — в [`AGENTS.md`](AGENTS.md).
