# Specs — Spec-Driven Development

Спецификации поведения мода. Каждая спека — критерий приёмки для соответствующей
фичи; код должен удовлетворять спеке, изменения поведения — сначала менять спеку.

- `validation-rules.md` — валидация списков правил приоритетов забоя
  (дубликаты, покрытие, событийное закрытие сетов, исчерпание).
